# InkUrban

InkUrban is a Java desktop application that simulates a graffiti and urban art products store. It was originally developed for a university course on Object-Oriented Programming, and has since become an ongoing personal project — one I continue to extend and refine as I learn new concepts.

The application includes two dedicated views, one for administrators and one for customers, and covers the core workflow of a real store: authentication, product management, shopping cart handling, sales registration, and invoice generation.

This is not a closed, one-time assignment. InkUrban is where I apply what I learn as I go, and it will keep growing alongside my skills — the next planned step is adding persistent storage through a database.

## About the Project

This project was developed to practice object-oriented programming by building a desktop application from start to finish.

One of the biggest challenges was designing the shopping cart so that each user had their own cart during the execution of the program. Solving that problem helped me better understand how to organize classes and manage objects within an application.

The project also gave me practical experience working with Java Swing and UML diagrams.

InkUrban remains a work in progress by design. As I move forward in my studies and pick up new tools and concepts, I plan to keep expanding it rather than leaving it as a finished course deliverable — starting with proper database support.

## Current Limitations

The application does not use a database yet.

All users, products and sales exist only while the program is running, so the information is not saved after closing the application.
